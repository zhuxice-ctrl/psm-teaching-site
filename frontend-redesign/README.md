# PSM AI 训练营 · 奶油乐园

> 一个交互完整、可在浏览器直接体验的"PSM 少儿 AI 教学站"前端实现。

## 目标

把原 PSM 教学站的真实功能（Flask + SQLite + AGNES AI）映射成纯前端单页应用，
保留 **一套设计语言**（奶油乐园），并把整站做成「可点的可演示的」。

## 主题

**唯一皮肤：奶油乐园**。点击打开就是奶油主题，演示与提交都走这套。

| 主题 | 状态 | 风格 |
| --- | --- | --- |
| 奶油乐园（当前） | 启用 | 奶油纸纹 · 大圆角贴纸 · 手写点缀 |
| 星夜探索 | 仓库 CSS 保留，未启用 | 深空玻璃 · 聚光跟随 · 星尘进度 |
| 像素工坊 | 仓库 CSS 保留，未启用 | 8-bit 街机 · 关卡卡 · 像素字体 |

如需切回星夜 / 像素：把 `index.html` 里 `theme-creamy.css` 那一行换成 `theme-cosmic.css` / `theme-pixel.css`，再把 JS 里 `applyTheme('creamy')` 改对应名即可（其它主题文件已就位）。

## 演示模式（登录已越过）

登录页按用户要求做成**演示直过**：不连数据库、不做任何校验，点击按钮即交互。

- **选择页直达**：点「老师进入」→ 直接进教师后台；点「学生进入」→ 直接以「小明」身份进课堂，完全跳过登录页。
- **登录页仍保留设计**：选择页底部小链接可进入学生 / 教师登录页；页面顶部有「演示模式」横幅，字段全部可留空（自动补 小明 / A1B2C3 / 演示老师），点按钮即入。
- 学生登录时若姓名不在名册，会**自动加入名册**，保证演示流程永不卡壳。

## 还原的真实功能

- **身份选择**：老师进入 / 学生进入（演示免登录直达）
- **学生登录页**：姓名 + 手机尾号（4 位，可选）+ 班级码（6 位字母数字）— 演示模式不校验
- **教师登录页**：用户名密码 — 演示模式不校验，可留空
- **课时页 L1-L10**：
  - 文字 / 图片额度条
  - 5 种活动卡：discussion / agnes_text / agnes_image / create / external
  - **askText 进度条假动画**：12% → 92%，900ms 间隔，3 段提示
  - **askImage 进度条假动画**：8% → 95%，1200ms 间隔，4 段提示，含"前面还有 N 个任务"
  - 额度归零自动禁用按钮
  - 学生原创作品提交
- **L7-L9 编程世界**：外链 psm.steam.fun + 编程截图上传
- **班级展示墙**：通过审核的作品
- **L10 作品集**：精选 + 全部
- **教师后台**：创建班级（自动生成 6 位班级码）、学生名册、批量导入
- **课次管理**：添加课次
- **作品审核**：状态过滤（全部 / 待审核 / 已通过 / 已驳回）+ 课次过滤 + 评语 + 通过 / 驳回

## 演示账号

演示模式下**无需账号**：选择页两张大卡直接进；登录页字段全留空点按钮也直接进（自动补 小明 / A1B2C3 / 演示老师）。

## 本地预览

```bash
# 任何静态文件服务器即可（不需要后端）
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

数据存储在 `localStorage` 的 `psm_db_v1` 与 `psm_session` 中，刷新会保留。
清空浏览器存储可重置为种子数据。

## 技术栈

- 纯 HTML / CSS / JS（无构建步骤）
- CSS 变量驱动主题切换（`body[data-theme="..."]`）
- Google Fonts 走妙搭自托管镜像 `miaoda.feishu.cn/fonts`
- 资产走 `assets/images/` 相对路径，6 张预生成配图

## 文件

- `index.html` — 单页骨架，10 个 view 区段
- `base.css` — 极简重置 + view 显隐
- `theme-cosmic.css` / `theme-creamy.css` / `theme-pixel.css` — 三套主题
- `app.js` — 主题管理 + 数据层 + 路由 + 视图渲染 + 交互逻辑
- `assets/images/` — 6 张 AI 教学站配图
