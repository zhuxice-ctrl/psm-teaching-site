## Scope

This repository is a sanitized source snapshot. It excludes production database files, uploads, generated output, logs, venv, backups, and all secret-bearing files.

## Run locally

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt  # if present
python run.py
```
